# Adotaê 🐾

Projeto escolar de um site simples para divulgar animais disponíveis para adoção.

## Como abrir
1. Instale o Node.js.
2. Abra a pasta do projeto no VS Code.
3. No terminal, execute `npm install`.
4. Depois execute `npm run dev`.
5. Abra o endereço que aparecer no terminal.

## Sobre o projeto
O site usa dados fictícios e não possui banco de dados, login ou envio real de mensagens. As publicações feitas pelo formulário ficam apenas na memória enquanto a página está aberta.

## Telas
Início, Resultados, Detalhe, Publicar, Minha conta e Rota inexistente.
